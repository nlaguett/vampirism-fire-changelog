# Vampirism Fire 8.1i

---

## Main

- **Ring of Protection**
  - Now grants **+1000 HP**

- Added new Vampire gold-sharing system:
  - `-share gold`
  - Teammates can receive your gold using `-rg`

- Updated clan members list
- Applied Tournaments point system temporarily as "testing" before the tournament.
- Fixed an issue causing *Gold Mine* count loss when cancelling a *gold mine*
- **Black Buildings** now correctly display bonus gold
- Improved **tax system** to properly award gold when Vampires are taxed
- **Blood Tower** priority set to lowest
- **Comet Tower** priority set to highest
- [Main-Builders] no longer provide vision between **0:55 and 5:00**

### Pro Mode Changes
- Removed Demolisher +500 damage buff



### Attack Type Rework

**Normal Attack**
- Damage against Fortified reduced **200% → 150%**

**Siege Attack**
- Damage against Fortified increased **200% → 250%**
- Damage against Bestial reduced **150% → 125%**

## Training Mode

- Added command `-hp`
  - Sets a unit’s HP
- Added command `-damage`
  - Sets a unit’s base damage
- Added command `-tp`
  - Teleports your Vampire around the map

- Fixed issue where Human HP would not correctly apply if Training Mode was enabled before map initialization
